# Contributing To DanShen

Bug reports, focused feature proposals, documentation improvements, and code
contributions are welcome.

## Before Opening A Pull Request

1. Create a branch from `main`.
2. Keep the change focused and avoid unrelated formatting or refactors.
3. Run `./script/build_and_run.sh --verify`.
4. Confirm that no API keys, credentials, personal files, chat history, calendar
   data, or local absolute paths are included.
5. Describe the user-visible behavior and include screenshots for UI changes.

DanShen is derived from Boring Notch. Fixes intended for the upstream project
should be submitted directly to
[TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch) under
its own contribution guidelines.
