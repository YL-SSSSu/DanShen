# Security Policy

Do not include API keys, passwords, private calendar data, chat history, or local
documents in a public issue.

For a security-sensitive report, use GitHub's private vulnerability reporting
for this repository. Include the affected version, reproduction steps, expected
impact, and any suggested mitigation. For ordinary bugs that do not expose
private data or credentials, open a normal GitHub issue.

Provider credentials are expected to remain in macOS Keychain. Release archives
must not contain local application data or developer credentials.
